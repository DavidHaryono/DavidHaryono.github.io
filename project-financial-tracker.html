AI-Powered Financial Tracker Platform

A collaborative full-stack web application designed to eliminate friction in manual budgeting by using automated multi-tier Vision LLM and OCR microservices to dynamically parse transactional data from receipts.

⚙️ [System Architecture Diagram: Client Upload ➔ Controller Streaming ➔ Vision Fallback Array ➔ MySQL Persistence]

Overview

Manual expense categorization and budget management are highly susceptible to user fatigue and clerical errors. This project solves that friction by introducing an automated, smart financial tracking layout built on top of the Laravel ecosystem.

The application serves as an integrated, multi-user solution allowing real-time ingestion of physical receipt uploads. The platform parses structural data (merchant title, total transactional amount, consumer category) and seamlessly maps them against active user thresholds to enforce automated household accounting rules.

System Architecture & Vision Pipelines

The core technological innovation lies inside the abstract ReceiptParserService, which operates a resilient multi-tier fallback pipeline utilizing vision-centric deep learning structures:

  1. Primary Vision Tier: Leverages the Groq API running llama-3.2-90b-vision-preview for rapid, low-latency extraction of textual contexts paired with exact base64 image data matrix streams.
  2. Secondary Vision Tier: In the event of primary exhaustion, a fallback layer calls Together AI running meta-llama/Llama-3.2-11B-Vision-Instruct-Turbo.
  3. Hybrid Tesseract Layer: Executes local client-side Tesseract OCR across multiple page segmentation modes (PSM), subsequently feeding extracted text tokens into an analytical llama-3.1-70b-versatile model to construct structured JSON representations.
  4. Deterministic Fallback: Employs structured regex pattern matching and word score matrices to isolate fiscal numbers and merchant strings when standard web connectivity drops.

Backend Architecture & Data Schema

Beyond processing image files, the platform utilizes relational Eloquent ORM models to track state distributions across segmented budgets (transportation, food, home_utilities, and entertainment).

The underlying transactional scheme securely handles state verification and user configuration settings across specialized middleware routers (LocaleMiddleware and CheckSession). This structure keeps active session data completely clean while running monthly cumulative aggregation query filters directly in the SQL engine to calculate active remaining balances.
