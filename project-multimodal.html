Multimodal Misinformation Detection Model

A research-grade deep learning architecture designed to combat online misinformation by cross-referencing and fusing semantic textual embeddings with high-dimensional visual feature spaces.

Overview

Modern digital misinformation is increasingly complex, frequently combining authentic imagery with fabricated text to deceive traditional text-only classification systems. Rather than treating text headlines or visual elements as isolated factors, this project introduces an integrated deep learning architecture that flags contradictions and mismatches between modalities.

Trained on the massive 106GB Fakeddit dataset, this model establishes a higher barrier against deceptive media by analyzing cross-modal relationships directly inside a joint latent mathematical space.

Model Architecture & Fusion Strategy

The network runs parallel dual-stream feature extraction pipelines before concatenating the representations into a final multi-modal classification block:

  • Textual Pipeline (NLP): Utilizes a pre-trained bert-base-uncased transformer model to read contextual sequences from headlines, isolating the dense 768-dimensional [CLS] token's pooler representation.
  • Visual Pipeline (CV): Employs a pre-trained ResNet50 backbone (trained on ImageNet-1K), stripped of its final dense classification head, yielding a structural 2,048-dimensional representation vector of the image asset.
  • Cross-Modal Fusion Array: Mathematically concatenates the 768d text vector and 2,048d image vector into a single unified 2,816-dimensional feature array.
  • Classification Head: Feeds the combined 2,816-dimensional vector through a sequential dense stack: Linear(2816 -> 256) ➔ ReLU ➔ Dropout(p=0.3) ➔ Linear(256 -> 1), finalized with a Sigmoid activation for final binary authenticity output.

My Research Contributions

Working closely alongside my co-researcher, Evan Samuel Widjaja, my engineering ownership focused heavily on the natural language processing pipeline and the mathematical implementation of the cross-modal alignment framework:

  • Fusion Architecture Design: Conceived and built the alignment module that structurally joins disparate tensor weights into a cohesive multimodal representation space.
  • Transformer Optimization: Configured and tuned the bert-base-uncased NLP processing parameters to safely capture deep semantic cues from headline sentences.
  • Classification Tuning & Regularization: Structured the sequential layers of the deep classification head and optimized the dropout probability ratios to heavily reduce overfitting over the multi-epoch training iterations.

Experimental Results & Trust-Safety Impact

Following a complete **8-epoch training run** across the unseen test partitions of the Fakeddit ecosystem, the network reached peak performance metrics:

Metric Final Value
Classification Accuracy 82.834%
Precision 74.020%
Recall (Sensitivity) 87.386%
F1-Score 80.151%

The defining success of this architecture is its exceptionally high 87.386% Recall. In real-world trust and safety platform filtering systems, maximizing sensitivity is paramount because it heavily minimizes false negatives. This ensures that harmful, mismatched deceptive content rarely leaks past automated moderations unflagged.
